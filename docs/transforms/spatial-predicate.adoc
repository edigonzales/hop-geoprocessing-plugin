[[spatial-predicate]]
= Spatial Predicate
:plugin-id: SPATIAL_PREDICATE_TRANSFORM
:plugin-type: transform
:description: A primary stream and one secondary info stream.

[[spatial-predicate-description]]
== Description

`Spatial Predicate` compares a primary row against a cached secondary layer and returns either a
boolean, a filter decision, or an inner join.

[[spatial-predicate-input]]
== Input

Connect two independent producers to Spatial Predicate with regular hops. Hop 2.19 may warn
that their row layouts differ while both hops are still regular. Open Spatial Predicate
and choose the secondary producer in *Secondary info transform*. Click *OK* to assign
its hop to the *Secondary layer* info stream. The other hop supplies the primary rows.
An incoming hop alone does not assign it to the info stream.

The read-only dropdown lists producers with enabled incoming data hops. It does not accept
typed names. To switch producers, connect the new producer, remove the old secondary hop
if it is no longer needed, and choose the new producer in the dialog.

Spatial Predicate requires one primary producer and one secondary INFO row set per
copy of the predicate. Hop can feed multiple copies of the same primary producer
into one predicate.

Each geometry selector lists fields from its own stream. Use Select Values upstream to
convert WKT to native Geometry if needed.

For points within polygons, connect Points and Polygons, then select Polygons as the
secondary producer. Choose *Within*, the point and polygon geometry fields, and
`KEEP_MATCHED`. A point at (1, 1) matches a square from (0, 0) to (3, 3);
a point at (5, 5) is filtered out.

[[spatial-predicate-output]]
== Output

BOOLEAN_COLUMN appends a boolean. KEEP_MATCHED and KEEP_UNMATCHED filter rows and optionally route the opposite result to a reject target. INNER_JOIN emits one row per match. To assign a reject target, start the outgoing hop
on Spatial Predicate and select *Reject rows*. Hop saves this assignment in the
pipeline. Deleting the reject hop clears the assignment.

[[spatial-predicate-supported-engines]]
== Supported engines

Apache Hop 2.19.0 local pipeline engine, Java 21 or 25. The installed examples run with
the local engine. Distributed engines have not been validated by this repository.

[[spatial-predicate-error-handling]]
== Error handling

If the info hop is missing or disabled, the dialog asks you to connect both producers and
choose the secondary producer. A pipeline without a secondary assignment stops with
`Secondary layer info stream is not connected`. Enable or recreate the connection, select
the producer, and check both field mappings before running. Predicate filter rejects are normal routing, separate
from data errors.

[[spatial-predicate-limitations]]
== Limitations

The secondary layer must fit in memory. All nonempty geometries with a known positive SRID must use the same SRID across both inputs. SRID 0 is treated as unknown. Distance thresholds must be finite and nonnegative. Previously, negative thresholds were treated as positive magnitudes. The minimum-distance predicate includes equality with the threshold. INNER_JOIN is unsupported for disjoint and distance_gte.

[[spatial-predicate-operations-in-this-family]]
=== Operations in This Family

* topological predicates: `intersects`, `contains`, `within`, `touches`, `crosses`, `overlaps`, `disjoint`
* distance predicates: `distance++_++lte`, `distance++_++gte`

Full list: <<reference-matrix-spatial-predicate,Reference Matrix>>

[[spatial-predicate-important-parameters]]
=== Important Parameters

* `primaryGeometryFieldName`
** geometry field from the primary input
* `secondaryGeometryFieldName`
** geometry field from the secondary info stream
* `resultMode`
** controls whether the output is a boolean column, a filter, or an inner join
* optional reject target hop
** `KEEP++_++MATCHED` and `KEEP++_++UNMATCHED` can send the opposite filter result to a second output stream
* `distance`
** threshold for `distance++_++lte` and `distance++_++gte`
* `BOOLEAN++_++COLUMN`
** writes `true/false` to a new column
* `KEEP++_++MATCHED`
** keeps matched primary rows
* `KEEP++_++UNMATCHED`
** keeps unmatched primary rows
* `INNER++_++JOIN`
** one primary row can produce multiple output rows

[[spatial-predicate-common-pitfalls]]
=== Common Pitfalls

* The secondary layer is fully read before the first primary row is processed.
* `INNER++_++JOIN` is not supported for `disjoint` or `distance++_++gte`.
* The reject target stream is only meaningful for the filter modes `KEEP++_++MATCHED` and `KEEP++_++UNMATCHED`.
* The spatial index reduces the candidate set, but full geometry evaluation is still required.
