[[reference-matrix-geometry-converter]]
== Geometry Converter

All representations are handled by the shared Geometry Type codec. Coordinates are Point-only; non-Point input to coordinate output follows the selected error mode. SRID handling is not reprojection. See <<geometry-converter,Geometry Converter>> for the format table, NULL/EMPTY rules and the required error connection.

[[reference-matrix-geometry-reproject]]
== Geometry Reproject

Reprojects native Geometry XY between two-dimensional geographic or projected EPSG
CRS. Source CRS comes from the consistent Geometry SRID or an explicit EPSG
override; one target CRS applies to the transform. Z/M remain unchanged. Exact
curves must be linearized first. No Swiss fine-correction grid or height
transformation is included. An error connection is required only for
`ROUTE_TO_ERROR`. See <<geometry-reproject,Geometry Reproject>> for axis order,
NULL/EMPTY behaviour, limitations and the runnable example.
